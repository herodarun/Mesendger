# Лайм — чат-комнаты

Раньше комнаты и сообщения хранились только в `localStorage` браузера, а `BroadcastChannel` синхронизировал вкладки лишь на одном устройстве. Поэтому код комнаты с другого телефона не находился, а сообщения не передавались. Теперь сайт использует Cloudflare Pages Functions и общую базу Cloudflare D1; список комнат в браузере остаётся только локальным списком удобных ссылок.

## Подключение Cloudflare Pages и D1

1. Разверните репозиторий именно в **Cloudflare Pages с подключением GitHub**. Для обычной статической загрузки одного `index.html` серверные функции не попадают в публикацию. В Pages выберите без фреймворка, оставьте команду сборки пустой, каталог сборки — корень репозитория (`.`). В репозитории должна публиковаться папка `functions/` вместе с сайтом. Если используете прямую загрузку, разверните сайт способом Cloudflare, который поддерживает Pages Functions, например через Wrangler.
2. В Cloudflare создайте базу **D1** (например, `lime-chat-db`). Откройте её SQL-консоль и выполните весь файл [`schema.sql`](schema.sql), чтобы создать таблицы комнат и сообщений.
3. В настройках проекта Pages добавьте привязку D1 (раздел может называться **Settings → Functions/Bindings → D1 database**):
   - имя переменной / binding: **`DB`** — именно так, заглавными буквами;
   - база данных: созданная на предыдущем шаге.
   Если собираетесь пользоваться Preview-деплоями, добавьте такую же привязку и для Preview-окружения.
4. После добавления binding запустите новый деплой последней версии репозитория.
5. Проверьте адрес `https://<имя-проекта>.pages.dev/api/health` (или свой домен). Успешный ответ: `{"ok":true}`. Если показана ошибка, в ней будет подсказка: проверить привязку `DB` или повторно выполнить `schema.sql`.

## Проверка на двух устройствах

1. Откройте один и тот же адрес опубликованного сайта на обоих устройствах.
2. На первом устройстве создайте комнату и передайте код.
3. На втором введите этот код в поле «Войти по коду».
4. Отправленные сообщения сохраняются в D1 и появляются на подключённых устройствах автоматически (проверка новых сообщений выполняется примерно раз в 2,5 секунды).

GitHub хранит исходный код, но сам по себе не является базой чата. Если открыть GitHub Pages или только статическую копию `index.html`, межустройственная переписка работать не будет — нужен именно Pages Functions с привязанной D1.

## Важно о данных

В этом варианте нет учётных записей и сквозного шифрования: код комнаты служит ключом доступа, а сообщения хранятся в D1. Не отправляйте здесь пароли и другую чувствительную информацию. Комнаты и сообщения, созданные старой локальной версией, не были загружены на сервер; их история автоматически не переносится. Создайте новую комнату после настройки D1.
